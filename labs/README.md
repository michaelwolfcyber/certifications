# Security Labs

Document authorized, reproducible hands-on work.

## Lab write-up structure

1. Objective and learning outcomes
2. Scope, authorization, and environment
3. Architecture and tools
4. Procedure
5. Observations and evidence
6. Findings and interpretation
7. Remediation or defensive implications
8. Lessons learned and references

Never include credentials, tokens, private IPs that expose sensitive environments, personal data, or details that would enable unauthorized access. Keep raw logs and private lab notes outside this public repository.
