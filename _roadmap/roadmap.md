# Cybersecurity Career Roadmap

## Career Objective

Build a technical cybersecurity career combining Computer Science, cybersecurity certifications, graduate cybersecurity education, DoD clearance, Army technical experience, and hands-on security engineering work.

The primary direction is DoD and defense-sector cybersecurity, with emphasis on cyber defense, security operations, detection engineering, vulnerability management, security engineering, and authorized offensive security.

---

## 1. Academic Foundation

### Complete

**B.S. Computer Science — Western Governors University**

Core foundation in programming, algorithms, operating systems, networking, databases, software engineering, and computer security.

### Planned

**M.S. Cybersecurity and Information Assurance — Western Governors University**

Graduate specialization focused on cybersecurity practice, analysis, defense, and advanced security concepts.

---

## 3. Cybersecurity Certification Path

### In Progress

**ISC2 Certified in Cybersecurity (CC)**  
Establishes a broad cybersecurity foundation across security principles, governance, IAM, networking, operations, and incident response.

**CompTIA Security+**  
Builds a broad security baseline across threats, vulnerabilities, architecture, IAM, operations, risk, and incident response.

### Planned

**CompTIA CySA+**  
Develops defensive capabilities in security monitoring, threat detection, vulnerability management, and incident response.

**CompTIA PenTest+**  
Develops offensive security capabilities in reconnaissance, vulnerability assessment, exploitation concepts, web and network testing, and reporting.

**AWS Cloud Practitioner**  
Provides a foundational cloud credential supporting continued development in cloud security.

### Advanced

**CISSP**  
Pursued after the required professional cybersecurity experience is established, with emphasis on broader security architecture, governance, risk, and security program knowledge.

## Guiding Principle

**Learn → Build → Document → Apply → Improve**

Education establishes the technical foundation.

Certifications validate cybersecurity knowledge.

Military experience develops practical technical capability.

Projects demonstrate hands-on application.

Professional experience develops specialization.

The goal is to combine these elements into a durable technical cybersecurity career.
