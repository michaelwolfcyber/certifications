# ISC2 CC Practice Exams

This folder is reserved for original practice questions and exam-review material.

## Review format

For each question, document:

- The tested objective
- The correct answer and reasoning
- Why the distractors are incorrect
- The underlying concept
- A source reference

Do not publish copied or recalled live exam questions. Keep personal scores, missed-question logs, and weak-area tracking in the private Obsidian vault.
