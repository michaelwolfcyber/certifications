## Study approach

The working study process lives in a private Obsidian vault:

1. Use the official study manual and NotebookLM to learn a topic.
2. Draft Cornell notes and verify them against the source material.
3. Rewrite the explanation in your own words.
4. Add links to reusable concepts in the Technical Knowledge library.
5. Test recall and record gaps privately.
6. Publish only reviewed, original, portfolio-ready notes here.

This repository is the curated publication layer, not a mirror of the private Obsidian vault.
