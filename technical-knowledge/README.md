## Writing standard

Create one focused note per concept. Explain what it is, why it matters, how it works, practical examples, common misconceptions, and links to related concepts. Certification-specific context belongs in the relevant certification space; reusable explanations belong here.

The private Obsidian vault is the working knowledge graph. This folder contains only reviewed, publishable notes.
